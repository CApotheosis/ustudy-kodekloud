# KodeKloud AI Program — Strong Junior (Program B)

Training materials for a 20-week AI upskilling program covering the full [KodeKloud AI Learning Path](https://kodekloud.com/learning-path/ai) (22 courses + AI Tutor), delivered to 2 cohorts of 25 engineers.

## Layout

- `docs/requirements/kodekloud-requirements.md` — the contractual source (ТЗ) for this program, plus the scope decisions made against it
- `docs/research/` — primary-source research notes (course catalogs, durations, etc.)
- `docs/adr/` — architectural/programmatic decisions, once any are recorded
- `curriculum/curriculum.md` — the sequenced course path (phases, prerequisites, hours)
- `curriculum/schedule.md` — the 20-week / 2-cohort calendar
- `curriculum/mentor-sessions.md` — session-by-session mentor guide (60 sessions)
- `admissions/qualification.md` — student prerequisites
- `admissions/screening-interview.md` — pre-course screening interview guide
- `my-docs/` — source contract documents (.docx)

See `CLAUDE.md` for how agent skills in this repo read issues, triage labels, and domain docs.
