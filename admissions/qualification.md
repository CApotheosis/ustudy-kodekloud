# Prerequisites

## Qualification

- Working software engineer (junior level, 0–2 yrs) or equivalent bootcamp/CS grad
- Comfortable reading/writing code independently — this path teaches AI tooling, not programming fundamentals

## Programming languages

- **Python** — required (PyTorch, OpenAI SDK, RAG, LangChain, LangGraph, MCP lab)
- **YAML** — light exposure (Ansible playbooks)
- **JavaScript/Node.js** — optional/nice-to-have (Cursor/Cline exercises, AI-Assisted Development frontend phase); not required, no longer gated by an MCP lab

## OS

- **macOS or Linux** preferred — most terminal-heavy labs (Claude Code, Ansible, Ollama, K8s demos) assume a Unix shell
- **Windows works with WSL2** — don't run these labs in raw PowerShell/cmd

## Other prerequisites

- Git/GitHub basics (clone, branch, commit, PR) — used constantly from week 5 on
- Comfortable in a terminal/CLI
- 16GB+ RAM machine (Ollama runs local models; Apple Silicon or an NVIDIA GPU helps but isn't required)
- Docker basics (containers come up in the Claude Code and K8s demos)
- Accounts/access sorted before week 1: GitHub Copilot license, OpenAI API key (small budget for API costs), Claude/Anthropic account, AWS + Azure free-tier accounts (for the cert courses)
