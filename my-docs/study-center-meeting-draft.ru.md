## 0. Главное для встречи

KodeKloud не просто перетасовал путь обучения ИИ — они **поменяли направления**. Полностью удалено из старой программы: PyTorch, AI-Assisted Development, GitHub Copilot (оба курса), Cline, AI-Assisted Ansible, Mastering GenAI with OpenAI, NVIDIA GenAI Cert, Fundamentals of RAG, LangChain, весь курс AI Agents, LangGraph. Добавлено: **Loop Engineering, Fundamentals of MLOps и трек AIOps Learn-By-Doing из 6 курсов** (мониторинг Prometheus/Grafana → авто-восстановление на Python → обнаружение аномалий/прогнозирование ML → распределённая трассировка/анализ первопричин → MLflow/Kubeflow). Итог: программа сместилась от «инструментов ИИ-ассистированного кодирования + фреймворков агентов» к **облачным AI-операциям / AIOps**.

Известное известное против неизвестного: **[ДОПУЩЕНИЕ]** несколько новых курсов (Vector DB, MCP, AI Agents Fundamentals, Cursor AI, Loop Engineering, Fundamentals of MLOps, все 6 AIOps-подкурсов) на момент выгрузки 5 сентября ещё не были опубликованы на платформе KodeKloud — их длительность и количество модулей предварительные и могут измениться до релиза.

## 3. Третья фаза — черновые решения

### 3a. Коррекция программы — предложенная новая структура фаз

**[РЕШЕНИЕ]** Вместо того чтобы заново выводить кастомный граф предпосылок, как это делала старая программа, я в основном следовал собственной 3-кластерной группировке KodeKloud — именно её видят студенты на платформе, и её проще защитить перед учебным центром, чем реорганизацию с нуля. Одно исключение: я вынес два сертификационных курса (AI-900, AWS AI Practitioner) из кластера 3 и перенёс их в начало, сохранив логику старого плана «сертификаты сначала для быстрых побед + общий словарь». AIOps остаётся в самом конце как капстоун-трек специализации, в порядке Beginner→Intermediate→Advanced, который сам KodeKloud использовал для этих шести курсов.

| Фаза | Курсы | Длительность | Заметки |
|---|---|---|---|
| **0 — Основы облака и ИИ** | AI-900 (4ч20м), AWS AI Practitioner (8ч20м) | ~12ч33м | Сертификаты сначала, быстрые победы, общий словарь перед практикой |
| **1 — Основы ИИ и контекста** | Prompt Engineering 101 (0.58ч), Vector Database for GenAI (4ч48м), MCP For Beginners (2ч23м), AI Agents Fundamentals (1ч55м) | ~9ч40м | Соответствует кластеру 1 KodeKloud |
| **2 — Инструменты разработки GenAI** | Intro to OpenAI (6ч23м), Claude Code For Beginners (8ч37м), Cursor AI (3ч53м, *опционально*), Generative AI in Practice (3ч49м, *опционально*), Ollama (2ч15м) | ~25ч | Соответствует кластеру 2 KodeKloud |
| **3 — Эксплуатация: MLOps и AIOps** | Loop Engineering (0ч45м), Fundamentals of MLOps (5ч12м, *опционально*), AIOps Learn-By-Doing ×6 (Beginner→Advanced) | ~6ч + AIOps (длительность TBD, не выпущено) | Капстоун/трек специализации |

**Известный итог: ~53ч**, против ~99ч22м старого плана — примерно **вдвое меньше** видеоконтента. **[ДОПУЩЕНИЕ]** Я расцениваю это как хорошую новость для презентации (больше времени на практику/менторство на час видео, либо более короткая программа), а не как пробел, который нужно заполнять — но это решение, в котором учебный центр может захотеть участвовать, поскольку длительность программы — часть того, что они продают. Отмечаю, не решаю, вам на рассмотрение.

**[ДОПУЩЕНИЕ]** Поскольку длительность AIOps неизвестна, я не могу зафиксировать количество недель. Черновая оценка: **14–16 недель** вместо 20, до появления часов AIOps после релиза этих курсов. Не озвучивайте эту цифру учебному центру как окончательную.

### 3b. Реструктуризация папок

**[РЕШЕНИЕ]** Текущая плоская файловая структура (`1. Introduction.md`, `2. Detailing for Clarity.md`, ... + `course-details.md` в папке каждого курса) хорошо работает для одномодульных курсов вроде Prompt Engineering 101, но не масштабируется на многомодульные курсы (например, Generative AI in Practice — 6 модулей / 33 темы). Предлагаемая конвенция на будущее:

- **Одномодульный курс** → плоская структура: `<курс>/N. Название урока.md`
- **Многомодульный курс** → `<курс>/Module N - Название/M. Название урока.md`

Переименование уже собранного контента пока не требуется (только у Prompt Eng 101 есть файлы уроков, и он одномодульный — конфликта нет). Применяется на будущее по мере получения нового контента.

### 3c. Коррекция приёмных требований

**[РЕШЕНИЕ]** Обусловлено напрямую изменением каталога:

- **Полностью убрать JS/Node.js** из предпосылок — это и так было «опционально/приятный бонус», требовалось только теперь удалённой фазой фронтенда AI-Assisted Development и старой лабораторной по MCP. В новом каталоге в этом больше нет нужды.
- **Поднять планку по опыту с Docker/K8s** — трек AIOps Advanced (MLflow/Kubeflow, обслуживание на K8s) и Automated Remediation (Docker SDK) опираются на них сильнее, чем когда-либо в старой программе. Текущий документ квалификации трактует Docker как «базовые знания, встречается в демо» — это недооценивает новое требование AIOps Advanced (явно указывает Python, Kubernetes, основы ML как предпосылки для этого курса).
- **Оставить Python обязательным** — если что, он стал ещё более центральным (автоматизация AIOps, обнаружение аномалий ML, пайплайны MLflow — всё на Python).
- **Облачные аккаунты** — по-прежнему нужны бесплатные тарифы Azure + AWS (AI-900, AWS AI Practitioner, лабы по векторам S3), как и раньше. Напрямую связано с вашим всё ещё открытым вопросом №1 в `tasks.md` про платные тарифы.
- **Собеседование при отборе** — вопрос про Docker (№4), вероятно, нужно сместить с «достаточно концептуального ответа» на как минимум «запускали ли вы контейнер / использовали ли docker-compose», учитывая, что новый курс AIOps Advanced предполагает реальную уверенность в K8s/Docker. **[ДОПУЩЕНИЕ]** — отмечаю, сам скрипт собеседования не переписывал, жду вашего решения.

### 3d. Решение по структуре уроков

**[РЕШЕНИЕ]** Сохранить существующий еженедельный ритм S1 (Старт) / S2 (Практика) / S3 (Обратная связь + углубление) из `mentor-sessions.md` — это фреймворк менторского ритма, не привязанный к конкретному содержанию курсов, поэтому он переживает смену каталога без изменений.

**[РЕШЕНИЕ]** Новое правило для коротких курсов: несколько новых курсов короче 1 часа видео (Prompt Engineering 101 — 0.58ч, Loop Engineering — 0.75ч). Вместо того чтобы выделять полную неделю на каждый (как делал старый план для каждого курса), **объединяйте курсы суммарно до ~1ч в одну неделю**, либо позвольте короткому курсу занять только часть недели (например, S1+S2), а освободившуюся сессию использовать под менторский стретч-проект. См. разобранный пример ниже — Prompt Engineering 101 комфортно помещается в одну неделю сам по себе, с запасом.

## 4. Разобранный пример — одна полная неделя (Фаза 1, Неделя 2: Prompt Engineering 101)

Составлено на основе реального содержания уроков в наличии (`AI Learning Path/1. Master AI, ML & Context Foundations/1. Prompt Engineering 101/`) — вставлено вами вручную во время прохождения курса, не скрейпинг, но это реальный контент курса и самый конкретный доступный на данный момент пример, а не заглушка.

**Курс:** Prompt Engineering 101 — уровень Associate, 1 модуль, 8 уроков/7 лабораторных, 0.58ч видео (закладывайте 2–3x на практику = ~1.5–2ч всего, комфортно умещается в одну неделю).

| Сессия | Роль | Содержание | Активность |
|---|---|---|---|
| **S1 — Старт** | Ведущий | Обзор лабораторной (Introduction) + Detailing for Clarity + Persona Play | Живая демонстрация на собственных примерах курса общее→точное (например, «Расскажи про изменение климата» → «Как изменение климата влияет на частоту ураганов в Атлантике за последнее десятилетие?»). Задание на подготовку к S2: каждый студент составляет 3 версии одного реального промпта из своей работы — общий, детальный, с персоной. |
| **S2 — Практика** | Коуч | Разделители (тройные обратные кавычки, тройные кавычки, XML-теги, ключевые разделители) + Пошаговое уточнение | Парное упражнение: взять «грязный» реальный промпт из подготовки к S1, переструктурировать с разделителями и разбить на явные шаги. Ментор ходит между парами, снимает блокеры. |
| **S3 — Обратная связь + углубление** | Ревью | Иллюстрирование через примеры (few-shot) + Указание длины вывода | **Стретч-задание:** написать один промпт для реальной задачи по программированию, объединяющий все 5 техник (детализация + персона + разделители + пошаговость + длина вывода) — строится прямо на их собственном промпте из S1/S2. Индивидуальный разбор домашнего задания по стандартному рубрику (запущено/выполнено · качество · мог(ла) объяснить подход · одно улучшение). Анонс следующей недели. |

**Доп. домашнее задание (перенесено из старого плана, всё ещё актуально):** сдать личную библиотеку паттернов промптов — по одному разобранному примеру на технику, из собственной предметной области.
