## Overview

Teaches turning raw operational data into actionable intelligence using machine learning, covering metrics, anomalies, logs, and forecasting through Python notebooks and real datasets. Learners build an AIOps intelligence pipeline ready for real-world operations.

## Requirements

None explicitly listed. Suitable for: SRE/DevOps engineers wanting to enhance monitoring with AI, platform teams building observability systems, data engineers integrating ML into operations, software engineers interested in production analytics, and beginners wanting practical ML experience using real operational datasets.

## Course Content

### Module 1: Introduction to AIOps & Intelligent Data Engineering (1 topic)
AI-augmented observability, feature engineering, time-based features, lag/rolling window features.

### Module 2: Intelligent Anomaly Detection with Isolation Forest & LOF (1 topic)
Isolation Forest training, Local Outlier Factor, confidence scoring, contamination tuning.

### Module 3: Log Clustering & Pattern Discovery Using TF-IDF and K-Means (1 topic)
TF-IDF vectorization, K-Means clustering, silhouette/inertia evaluation, cluster labeling.

### Module 4: Time-Series Forecasting for Capacity Planning (1 topic)
SARIMA, Exponential Smoothing, MAE/RMSE/MAPE evaluation, confidence interval visualization.

### Module 5: Final AIOps Automation Project: Intelligent Monitoring Dashboard (1 topic)
Combines anomalies, log clusters, and forecasts into a final dashboard/report.
