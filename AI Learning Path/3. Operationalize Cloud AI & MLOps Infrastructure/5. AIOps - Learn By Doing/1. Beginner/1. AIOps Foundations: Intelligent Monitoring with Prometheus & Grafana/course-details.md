## Overview

Teaches learners to build monitoring systems that move past simple threshold-based alerts, using Prometheus, Grafana, and Python-based machine learning. Structured around the "AIOps Pyramid" framework, covering data collection, AI-driven analysis, and automated response actions.

## Course Content

Single module — 5 topics (no per-topic duration given on the page):

1. **The "AI" in AIOps: From Data to Decisions** — AIOps value proposition, the AIOps Pyramid concept, why metrics suit ML use cases, deploying a monitoring environment.
2. **Collecting the Data Fuel: Prometheus & Exporters** — Prometheus's pull-based collection model, exposition format, scrape job configuration, Node Exporter deployment.
3. **Basic Analysis with PromQL & The Limits of Manual Thresholds** — PromQL basics, label filtering, aggregations, counter-to-rate conversions, threshold alerting limitations.
4. **AI-Powered Anomaly Detection** — scikit-learn setup, training IsolationForest models, feature engineering, real-time anomaly detection.
5. **AI-Driven Forecasting for Proactive Operations** — Prophet setup, additive time-series modeling, forecasting with confidence intervals, capacity planning.
