## Overview

Teaches learners to build an observability stack using Grafana Loki, Alloy, and Prometheus, moving past log theory into hands-on deployment, log querying, and alert design meant to reduce noise rather than add to it.

## Course Content

Single module — 5 topics (no per-topic duration given on the page):

1. **Introduction to Loki** — core problems Loki solves, label-based indexing architecture, deployment overview, the LGTM (Loki, Grafana, Tempo, Mimir) stack concept.
2. **Centralized Logging Loki** — hands-on deployment of Loki, Grafana Alloy, and a sample application using Docker Compose, plus structured logging in a Python Flask app.
3. **Querying Logs LogQL** — LogQL syntax (compared to PromQL), stream selectors, line filters, parser expressions (json, logfmt).
4. **Correlating Metrics and Logs** — linking Prometheus metrics with Loki logs via Grafana "data links," building unified dashboards.
5. **Intelligent Alerting Alertmanager** — Prometheus alert rules, Alertmanager setup, alert grouping, inhibition rules, silencing, multi-team routing tree design.
