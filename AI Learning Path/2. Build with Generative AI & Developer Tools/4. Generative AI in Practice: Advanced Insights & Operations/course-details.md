## Overview

Builds skills in operating and deploying large language models. Covers the shift from rule-based approaches to sophisticated generative systems powered by transformers and multimodal architectures, plus responsible AI practices addressing biases, data drifts, and ethical considerations. Includes hands-on work with Azure AI Studio and covers Retrieval Augmented Generation (RAG) — a hybrid architecture enhancing model capabilities via real-time data retrieval.
