## 4. Does KodeKloud group these into an explicit "DevOps/Platform AI specialization" learning path?

**No explicit combined path found.** Findings from https://kodekloud.com/learning-paths/ (fetched directly — full index of all named learning paths on the site):

- **Role-based paths** listed: System Administrator, Kubernetes Administrator, Site Reliability Engineer, Kubernetes Developer, **Platform Engineer** (12 courses, 170h), **DevOps Engineer** (17 courses, 350h), Cloud Engineer — none of these role paths are AI-specific.
- **Domain-based paths** listed: **Artificial Intelligence** (19 courses, 140h), CKA/CKAD/CKS/KCNA, Linux, Kubernetes, Kubestronaut/Golden Kubestronaut, IAC, HashiCorp, CI/CD, **DevOps** (14 courses, 170h), Programming, Docker, AWS, Azure, GCP, Cloud, Learn-By-Doing, IT Foundations, and **AIOps** (6 courses, 20h).
- No path is named "DevOps AI Specialization," "MLOps Path," or "Platform Engineering AI" on this index. The closest candidates are the generic **AI** path and the **AIOps** path, both distinct from — and not merged with — the **DevOps** or **Platform Engineer** paths.
- Attempted direct fetch of `kodekloud.com/learning-path/aiops` returned **HTTP 404** — this exact URL slug does not exist; the AIOps path (if live) is under a different URL not identified in this research pass.
- The dedicated **AI Learning Path** page (https://kodekloud.com/learning-path/ai) was fetched directly and its full course list extracted. **None of the three target courses (Fundamentals of MLOps, AWS SageMaker, Introduction to K8sGPT) appear in this AI Learning Path's course list.** The path instead comprises the 22 courses already documented elsewhere in this project (AI-900, AWS Certified AI Practitioner, PyTorch, AI-Assisted Development, GitHub Copilot in Action, GitHub Copilot Certification, Cursor AI, Claude Code For Beginners, Cline, AI Assisted Ansible, Prompt Engineering 101, Introduction to OpenAI, Mastering Generative AI with OpenAI, Generative AI in Practice, Running Local LLMs With Ollama, NVIDIA GenAI LLMs Associate Cert, Vector Databases, Fundamentals of RAG, MCP For Beginners, LangChain, AI Agents Fundamentals, AI Agents, LangGraph), plus an "AI Tutor" item with no duration listed. (Source: https://kodekloud.com/learning-path/ai)

**Conclusion:** KodeKloud does not currently publish an explicit "DevOps/Platform AI specialization" learning path that bundles Fundamentals of MLOps, AWS SageMaker, and the K8sGPT course together. These three courses exist as standalone catalog items (with the K8sGPT course apparently still in pre-release/phased rollout) that a curriculum designer would need to hand-select outside of KodeKloud's own path groupings — there is no official KodeKloud page that pre-packages this specific trio for a DevOps/Platform track.
