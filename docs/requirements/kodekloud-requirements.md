# Requirements — KodeKloud Strong Junior (Program B)

Source: ТЗ "Оказание услуг по повышению квалификации 100 сотрудников государственных органов по искусственному интеллекту" (100_AI_course_39.docx).

Structured learning path for Strong Junior technical staff.

## Admission

- English level ≥ B1 (CEFR), verified before start
- Strong Junior technical level (solid foundational skills, motivated for accelerated AI-tooling ramp-up)

## Duration & format

- Up to 5 months (20 weeks), 100% online
- Live mentoring + KodeKloud platform content, recorded sessions
- Weekly progress monitoring; targeted mentoring for students falling behind

## Structure (all three blocks required)

**1. Mandatory core**
1. Introduction to OpenAI
2. Learn by Doing – Prompt Engineering 101
3. AI-Assisted Development
4. GitHub Copilot Certification
5. Cursor AI
6. Claude Code For Beginners

**2. Cloud AI Fundamentals & engineering productivity block**
7. MCP For Beginners
8. Cline
9. AWS Certified AI Practitioner
10. Azure AI Fundamentals / Azure AI Engineer Associate

**3. One specialization (student picks one)**

*Software Developers*
11. LangChain
12. PyTorch
13. AI Agents
14. Practical integration block (LLM-enabled app design, chaining/retrieval/tool use, agent workflows)

*DevOps / Platform / Operations Engineers*
11. Fundamentals of MLOps
12. AWS SageMaker
13. Running Local LLMs With Ollama
14. Introduction to K8sGPT and AI-Driven Kubernetes Engineering

## Assessment forms

- Mini-checks after individual topics
- Checkpoint assessments after each block
- Practical assignments
- Mini projects
- Final assessment after core + specialization

## Completion criteria (all required simultaneously)

- Mandatory core completed
- Cloud AI Fundamentals block completed
- One specialization completed
- All checkpoints + final assessment passed
- All mandatory practical assignments/mini projects completed
- Completion confirmation issued

## Certification

- No proctored international exam requirement (unlike NVIDIA track) — this is a structured learning path, not a certification exam
- Completion confirmation may be issued by the **contractor (Исполнитель)** and/or by **KodeKloud** (platform), per §7 of Приложение 3 — exact form to be agreed with the customer (Заказчик) before training starts
- ≥80% of compliant students must complete their track (contract guarantee)

## Open item

- Exact grading thresholds, checkpoint pass criteria, and the specific completion-document form are **not fixed in the ТЗ** — must be agreed with Заказчик and documented in the calendar plan before training begins (§13.1.3).

## Program scope decision (this repo)

- This repo's program runs the full **KodeKloud AI Learning Path** catalog (kodekloud.com/learning-path/ai — 22 courses + AI Tutor) for **all 50 students**, rather than the ТЗ's core + cloud + pick-one-specialization structure.
- The ТЗ's **DevOps/Platform/Operations specialization** (Fundamentals of MLOps, AWS SageMaker, Running Local LLMs With Ollama, Introduction to K8sGPT) is **intentionally not offered** as a separate track. Note: MLOps, SageMaker, and K8sGPT aren't part of the AI Learning Path catalog at all (confirmed in `docs/research/devops-track-courses.md`), and the K8sGPT course is currently pre-release on KodeKloud. Splitting students into two tracks was rejected to avoid imbalance between cohorts — see conversation history for rationale.
- The Software Developer specialization courses (LangChain, PyTorch, AI Agents) **are** included, since they're already part of the AI Learning Path catalog everyone completes.

## Common requirements (both programs)

- Prior notification/consent from students on program terms, assessment rules, and consequences of not passing before training starts
- Data protection / access control on international platforms (personal cabinets, activity logs, materials)
- Post-program consultation support: 3 months (if included in contract)
- Deliverables to customer: interim + final reports, student rosters with status, completion documents registry, training materials, attendance/activity logs
