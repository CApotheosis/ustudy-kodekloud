## Overview

Teaches troubleshooting for microservice ecosystems using distributed tracing, offering visibility beyond traditional monitoring — revealing causal relationships, latency bottlenecks, and hidden failure points that logs and metrics alone can't expose. Students build skills through labs and real-world scenarios to apply AIOps for automated root cause analysis (RCA), learning to generate, collect, visualize, and correlate trace data with logs and metrics.

## Course Content

Single module — 5 topics (no per-topic duration given on the page):

1. **The Challenge of Microservices & The Rise of Distributed Tracing** — why traditional monitoring fails for microservices; OpenTelemetry as a vendor-neutral framework for trace data.
2. **Installing the OpenTelemetry Collector** — installing the Collector Contrib distribution; configuration structure (receivers, processors, exporters); reviewing startup logs.
3. **Instrumenting Applications with OpenTelemetry** — auto-instrumentation for Java and Python; OTLP export configuration to the Collector.
4. **Visualizing Traces with Jaeger** — installing Jaeger All-In-One; configuring the Collector to export via OTLP to Jaeger; accessing the Jaeger UI.
5. **Practical Root Cause Analysis with Distributed Traces** — interpreting traces/spans; identifying bottlenecks via timelines and critical paths; step-by-step workflow for pinpointing root causes.
